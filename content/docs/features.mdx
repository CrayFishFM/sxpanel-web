sxPanel bundles a web panel, an in-game admin menu, analytics, player management,
access control, a Discord bot and an addon system into a single build. This page
is a map: each item links to the page that explains it completely.

![sxPanel Overview dashboard — server controls, live player count, server stats, console and performance charts](/docs/overview.webp)

- [Installation](/docs/quick-start): requirements, replacing the `monitor` folder, first start and PIN

- [Migrating from txAdmin](/docs/migrating-from-txadmin): what carries over and how to go back

## Web Panel

A real-time control room for your server.

- [Overview dashboard](/docs/overview): server controls, players, stats, console tail and performance charts
- [Live console](/docs/live-console): real-time output, commands, search, filters and saved commands
- [Resources](/docs/resources): start, stop, restart and ensure resources, and edit their config files
- [CFG editor](/docs/cfg-editor): edit `server.cfg` and other `.cfg` files, with validation on save
- [Server log](/docs/server-log): joins, chat, deaths, combat and admin actions, live and replayed
- [Chat commands](/docs/chat-commands): built-in `/` commands and your own custom ones
- [Players](/docs/players): the roster and the player profile with every moderation action
- [History](/docs/history): bans and warnings, ban templates and durations
- [Reports](/docs/reports): player tickets and report analytics
- [Insights](/docs/insights): retention, peak hours, session length and player drops
- [System pages](/docs/system): Action Log, Console Log, Diagnostics and Advanced
- [Admins and permissions](/docs/permissions): accounts, presets, login methods and two-factor
- [Whitelist](/docs/whitelist): join workflows, requests and approvals
